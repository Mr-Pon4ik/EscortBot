
# EscortBot - Telegram бот для мониторинга домашнего сервера

## 🚀 Обзор
Telegram бот для мониторинга сервисов домашнего сервера. На данный момент поддерживает мониторинг SSH подключений с уведомлениями в реальном времени.

## 📋 Требования
- Python 3.12+
- Linux система
- Зависимости: смотри `requirements.txt`

## 🤖 Получение id чата
1. Создайте бота через @BotFather в Telegram.
2. При заполнении файла config.conf оставьте оставьте поле **chat_id** пустым. 
3. Запустите бота и получите ваш chat ID отправив `/start` боту.

## 🔧 Конфигурация
Файл конфигурации - `config.conf`
При заполнении `config.conf` файла вы можете использовать как переменные окружения внутри linux так и из файла .env.
Если вы не хотите использовать переменные окружения то вместо них введите значения параметров.

### Например
```ini
bot_token ESCORT_TELEGRAM_BOT_TOKEN          # Через переменные оркужения
bot_token 123456789:AAAbbbCccDddEeeFffGggHhh # Ввод значений напрямую
```

## 🚦 Использование
Файл запуска TelegramBot_for_HomeServer.py

## 📝 Логи
- Вывод в консоль + запись в файл
- Лог файл по умолчанию: `escort.log` в директории программы
- Уровень логирования настраивается в config.conf `debug_level`
